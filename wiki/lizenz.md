# Lizenz

Alle MRtechnology-Projekte stehen unter derselben **MRtechnology Lizenz 1.0** (source-available, nicht Open Source). Kurz gesagt:

| ✅ Erlaubt | ❌ Nicht erlaubt |
|---|---|
| Nutzen - privat und gewerblich, auch auf Servern mit Spenden, Rängen oder Shops | Weiterveröffentlichen (auch verändert), z.B. auf Modrinth, Spigot, in Modpacks, auf Discord oder in Server-Paketen |
| Verändern und neu kompilieren | Verkaufen oder gegen Geld anbieten |
| An dein Team oder deinen Hoster weitergeben | Als eigenes Werk ausgeben, Lizenzhinweis entfernen |
| Verbesserungen per Pull Request einreichen | |

Die Client-Mods dürfen Spieler nur aus der offiziellen Quelle beziehen (Seite **Downloads**). Die Nutzung erfolgt auf eigenes Risiko - leg vor Updates eine Sicherung an.

Maßgeblich ist der vollständige Text in der Datei `LICENSE` jedes Repos (Deutsch verbindlich, mit englischer Fassung), z.B. [LICENSE von MRadmin](https://github.com/therealmarci/mradmin/blob/main/LICENSE).
