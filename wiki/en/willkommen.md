# Welcome

**MRtechnology** makes small, well thought-out extensions for Minecraft servers running Paper - two of them with a matching Fabric mod for the players. Everything is configurable, every message translatable, and every feature has its own permission.

## The projects
| Project | What it does |
|---|---|
| [MRadmin](https://mrtechnology.marcelr.at/wiki/mradmin/) | Admin toolbox: maintenance, tickets, staff chat, announcements, web interface - and the link between the other plugins |
| [MRsleep](https://mrtechnology.marcelr.at/wiki/mrsleep/) | Fair sleep quota with exemptions and `/nosleep` for farm builders |
| [MRchunks](https://mrtechnology.marcelr.at/wiki/mrchunks/) | Chunk loaders with a chunk budget, invitations and lag protection |
| [MRpvp](https://mrtechnology.marcelr.at/wiki/mrpvp/) | Duels in their own arenas with kits and their own statistics |
| [MRtoolbar](https://mrtechnology.marcelr.at/wiki/mrtoolbar/) | Tool belt: switch tools with a key press (plugin + mod) |
| [MRwaypoints](https://mrtechnology.marcelr.at/wiki/mrwaypoints/) | Shared server waypoints, also in Xaero's Minimap (plugin + mod) |

Every plugin runs **on its own**. Together with [MRadmin](https://mrtechnology.marcelr.at/wiki/allgemein/zusammenarbeit/) they can do more.

## Where do I find what?
- **You play** on a server with these plugins? Every project has a section **For players**.
- **You run a server?** Start with [Install & update](https://mrtechnology.marcelr.at/wiki/allgemein/installieren/) and [Permissions with LuckPerms](https://mrtechnology.marcelr.at/wiki/allgemein/rechte/), then the plugin's pages **For admins**.
- **Search:** top right or with `Ctrl` + `K` - finds commands, permissions and settings in all plugins.
- **Something is wrong?** With **Report a bug** in the top bar your report goes straight to the right project.

> [!NOTE]
> The wiki shows the state of the **released** versions. If there are already changes for the next version, the link "View unreleased state" is at the bottom of the page.
